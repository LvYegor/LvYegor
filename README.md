### What I do

- Python Engineer at Yumasoft, building the integration platform behind **Calibrate HCM** (US HR-tech): it connects 50+ HR and payroll systems and is replacing 130+ hand-written vendor scripts. A new integration is now assembled from reusable steps in days instead of weeks of coding.
- Distributed, event-driven backends on AWS: SQS FIFO, Lambda, ECS Fargate, EventBridge, exactly-once webhook pipelines, per-endpoint rate limiting, infrastructure as code with CloudFormation/SAM.
- Integrations with third-party APIs that behave badly: verifying writes by re-reading, idempotent retries, reconciliation runs.

Most of this work lives in private client repositories, so the contribution graph below is the public trace of it. Ask me about Python, backend architecture, API integrations and async systems.
